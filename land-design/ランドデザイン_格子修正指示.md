# ランドデザイン index.html 修正指示
## 件名：HEROセクションの格子模様をカード側（右半分）だけに寄せる

### 問題
`.hero-pattern` の格子（細い十字の線）がHERO全体に広がっており、
左側のキャッチコピー「地域密着15年」などのテキストにかぶってしまっている。

### 修正内容
`index.html` の `.hero-pattern` のCSSを以下のように書き換える。

#### 【変更前】
```css
.hero-pattern {
  position: absolute; inset: 0;
  background-image: linear-gradient(rgba(184,150,78,0.04) 1px, transparent 1px), linear-gradient(90deg, rgba(184,150,78,0.04) 1px, transparent 1px);
  background-size: 60px 60px;
}
```

#### 【変更後】
```css
.hero-pattern {
  position: absolute;
  top: 0; bottom: 0;
  right: 0;
  left: 50%;
  background-image: linear-gradient(rgba(184,150,78,0.06) 1px, transparent 1px), linear-gradient(90deg, rgba(184,150,78,0.06) 1px, transparent 1px);
  background-size: 60px 60px;
}
```

### 変更のポイント
- `inset: 0`（全体）→ `left: 50%`（右半分だけ）に変更
- 格子の透明度を `0.04` → `0.06` に少し上げて、右側では見えやすく補正
- テキスト側（左半分）には格子が一切かからなくなる

### 作業後の確認
1. ブラウザでindex.htmlを開き、HEROのキャッチコピーに格子がかぶっていないことを確認
2. 右側のカードエリアには格子が残っていることを確認
3. スマホ表示でも格子がテキストにかぶっていないことを確認（スマホでは左右が縦積みになるため、格子はほぼ見えなくなるが問題なし）
