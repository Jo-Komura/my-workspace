## 1. これは何
- はるひ（3歳）用ミニゲーム第3弾。中身は**もぐら叩き**。アザラシが流氷の穴からひょこっと出てくる。
- 「はるひ基準」に合わせて、**叩く＝触れたら嬉しい**に変換（叱られ感ゼロ）。

## 2. はるひ基準（くまさんキャッチと共通）
- **罰なし・ゲームオーバーなし・エンドレス**。
- スコア（🐟）は**増えるだけ**。アザラシに触れば必ず +1・キラキラ・「ポンッ」。
- 触り損ねたアザラシは**自分で引っ込むだけ**（減点なし）。
- 操作は**触るだけ**＝3歳の指で迷わない。

## 3. 画面・ルール
- 背景：流氷（穴4つ・2×2配置）。
- アザラシが穴から出る → **触るとキャッチ成功**（+1・キラキラ・ポンッ）。
- 上中央＝スコア「🐟 ◯」。左上＝「もどる」、右上＝「設定」（ともに `shared` の画像アイコン btn-back.png / btn-settei.png ＝タイトル画面と統一。旧・黄文字「もどる」＆絵文字⚙から差し替え）。
- ⚙パネル（親用・漢字表記）：見出し「設定」＋**「アザラシが帰る速さ」1項目のみ（1〜5・初期2）**＝穴に帰る速さ＝出てる長さ(stay)＋「閉じる」。旧「アザラシのかず」は実テンポでほぼ効かないため削除し、同時に出る最大数は内部で `MAX_UP=2` 固定。パネルの文字は**固定px**（見出し20/項目16/ボタン18・箱max320px）＝子ども向けのゲーム部分(vw)と違い端末で巨大化しない“普通サイズ”。
- **出る頻度**：`spawnInterval`（はやさ2で1560ms）＝当初の倍にして“まばら”に（はるひが1匹ずつ落ち着いて狙えるテンポ）。

## 4. Android 7.0 対策（くまさんキャッチと同じ作法）
- `clamp()` / `aspect-ratio` を使わず、舞台の寸法はJSで実寸指定。
- 2018年以降の絵文字を使わない（🦭は□に化けるため**アザラシは画像/図形で描画**）。スコアの🐟・⚙は古い端末でも安全な字。
- Web Audio は try/catch で握りつぶし＝音が出なくても継続。

## 5. 絵の差し込み（v1→格上げ）

  - `images/bg.jpg` … 流氷＋穴4つの背景

### `HOLES` 実測メモ（2026-06-27 実機で確定）
- 左上 `{x:44.5, y:13.8}` ／ 右上 `{x:67.75, y:12.8}` ／ 左下 `{x:44.5, y:33.8}` ／ 右下 `{x:67.75, y:34.8}`
- 換算の目安（このタブレット）：横 **1cm ≒ 4.5%**（舞台幅≒22cm）／縦 **1cm ≒ 7.2%**（背景が横長＝ASPECT 0.621 ぶん縦が短い）。次に別端末で合わせ直す時はこの比率からスタート。
- ハンマー演出（hammer.png）は**空振りのタップの時だけ**出る（ヒット時はchara2に叩かれ顔＝ハンマー内蔵のため出さない）。`index.html` 冒頭の `SHOW_TAP_HAMMER` を false にすると空振りでも出さない（完全オフ）。仕組み＝`catchSeal`で`tapHitSeal`を立て、舞台の`showWhack`がそれを見てスキップ。
- **空振りの音**（`shared/se/karaburi.mp3`）も `showWhack` の空振り分岐で鳴る。ハンマー表示の `SHOW_TAP_HAMMER` とは独立（オフでも音は鳴る／ゲーム中・設定パネルを閉じている時だけ）。ヒット時は鳴らない（`piko` のみ）。
- **ボタンは空振り扱いしない**：`bindWhack` の `onDown` 先頭で `ev.target.closest('button, a')` を見て、設定(gear)・もどる(back)等のボタンを押した時は `showWhack` を呼ばない（＝ハンマーも空振り音も出ない）。アザラシ本体は `div` なので除外に引っかからない。ボタン側は別途 `click` で `se('click')`（クリック音）。

### 前フチ（リップ）実測メモ（2026-06-27 実機で確定）
- `CUTS = { mid: 53.6, bottom: 72 }`（舞台の高さに対する％。背景を 上／中／下 に分ける2本の境目）。
- 位置・サイズ・background-position は `layout()→positionBands()` がpxで自動計算。境目を動かしたい時はこの `CUTS` 2値だけ調整。
