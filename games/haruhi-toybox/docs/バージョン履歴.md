# はるひのおもちゃ箱 ・ バージョン履歴

アプリ画面の**右下に出ている番号（例 `v1.2`）**が、今タブレットに入っている版。
この表で「その版で何を直したか／まだ残っている宿題は何か」を突き合わせられる。
新しい版を作ったら、ここに1行足す（`app/build.gradle` の `versionName` と、`src/index.html` の `#ver` の表示も合わせる）。

| 版 | 日付 | 直したこと | まだ残っている（既知） |
|----|------|-----------|----------------------|
| v1.0 | 2026-06-29 | 初のAPK化（自前WebViewラッパーで包む。完全オフライン・全画面・横向き固定） | `_shared`（共通の画像・BGM・効果音）がAPKに入らず：BGMが鳴らない／設定・もどるのアイコンが出ない／「できたー！」画像が出ない。「おわる」も無反応 |
| v1.1 | 2026-06-29 | `_shared` 未収録バグを修正（build.gradle の ignoreAssetsPattern で `_`始まりフォルダを含める）→ BGM・アイコン・「できたー！」画像が出るように | 「おわる」ボタンが無反応（`window.close()` はアプリを閉じられない） |
| v1.2 | 2026-06-30 | ①「おわる」を本物のアプリ終了に修正（Web→Android の橋 `HaruhiApp.exit()` → `finish()`）②右下にバージョン表示を追加 ③新構造 `haruhi-toybox/src` から収録（`_shared`→`shared` で build.gradle のおまじない撤去） | 「おわる」でアプリは閉じるが、WebViewを破棄しないため**BGMが1曲分鳴り続ける**（実機で発覚） |
| v1.3 | 2026-06-30 | アプリ終了時に WebView を破棄（`onDestroy` で `about:blank`→`destroy()`）＝おわる後にBGMが鳴り続ける不具合を解消。あわせて裏に回った時（ホームボタン等）も `onPause`/`onResume` でBGMを停止・再開 | 有料版（親が子の名前を入れるパーソナライズ）は未着手＝後回し。借り物素材の差し替え・細部の作り込みも今後 |

## 版を上げる時の手順（メモ）

1. `src/` 側でゲーム本体を直す（H: の正本）。
2. 表示バージョンを更新：`src/index.html` の `<div id="ver">v1.x</div>`。
3. ビルド設定を更新：`C:\Users\thinkdev0\HaruhiToybox\app\build.gradle` の `versionCode`（+1）と `versionName "1.x"`。
4. assets を入れ替え：C: の `app\src\main\assets\app\` を H: の `src\` で上書きコピー。
5. ビルド（手順は `制作記録.md` / 引き継ぎノート参照）→ 出来た `app-debug.apk` を H: の `はるひのおもちゃ箱_v1.x.apk` に保存。
6. エミュ `haruhi_a7` か実機で確認 → この表に1行追記。
