## 1. 目的・対象ユーザー

- **誰のため**：ジョーの娘（3歳）。
- **ねらい**：勝ち負け・終わりのない「ただ楽しくキャッチするだけ」で大喜びできる、3歳児にやさしい安心ゲーム。
- **設計思想**：
  - 落としても**罰なし・ゲームオーバーなし**（叱られる感じがゼロ）。
  - スコア（🍎の数）は**増えるだけ**＝触れば必ず嬉しいことが起きる。
  - 操作は左右だけ＝3歳の指でも迷わない。

> ※「今のまま完璧」と確定していた（2026-06-26）が、**2026-06-27にケーキ完成＝クリアを追加し、画像版へ刷新**（はるひ基準は維持）。詳細は§6【2.0】。

## 2. 対象端末と制約

- **端末**：ジョーが約14年前に購入したAndroidタブレット（娘専用機）。
- **OS**：**Android 7.0**（2016年）。
- **表示エンジン**：Android System WebView（7.0世代＝Chromium 51相当。ただしPlayストアで更新可能）。
- **この世代の制約と対応**：
  | 制約 | 内容 | 本作での対応 |
  |---|---|---|
  | 新しいCSS `clamp()` 非対応 | 文字サイズ指定が無視され小さく出る恐れ | `vw`のフォールバックを併記（更新後はclamp優先） |
  | 絵文字辞書が2016年版 | 2018年以降の絵文字（🧁等）が□に化ける | フルーツから新しい絵文字を排除（🧁→🍰） |
  | Canvasの `roundRect()` 非対応 | 壁の角丸が描けない | 角丸が無理なら直角で描くフォールバックを実装済み（無害） |
  | Web Audio API 非対応の可能性 | 効果音が鳴らない端末あり | try/catchで握りつぶし＝音が出なくてもゲームは継続 |

## 3. ゲーム仕様（現状＝確定版）

### 3-1. 画面構成
- 背景：上＝空（水色グラデ）／下＝草地（緑）。
- **くまさん**：籠を持って画面下を左右に移動（Canvasで描画。絵文字ではない）。
- 左右の**低い杭（壁）**：「ここまでだよ」の移動限界の目印。
- 上部中央：**スコア表示**「🍎 ◯」。
- 右上：**⚙️ 調節ボタン**（親用）。
- 下部：左右の**大きな透明ボタン**（タッチ操作用）。

### 3-2. ルール
- フルーツ等が画面上からゆらゆら落ちてくる（🍎🍊🍓🍌🍇🍑🍉🍒⭐🍩🍰🍪 からランダム）。
- くまさんの籠に重なると**キャッチ成功**：スコア+1・キラキラ演出・「ポンッ」と効果音。
- キャッチできず下まで落ちたものは**ただ消えるだけ**（減点なし・終了なし）。
- **エンドレス**（クリアもゲームオーバーも無い）。

### 3-3. 操作
- **タッチ＝目的地方式（2.0で変更）**：画面の**押した列へクマが向かって歩き、着いたら止まる**。指を滑らせると追従。クマが行けない右側（テーブル）を押したら**一番右まで行って待つ**。
  - 狙い：3歳は「落ちてくるフルーツを指でつつく」のが自然な動き。その指の位置へクマが向かう＝教えなくても遊べる。
- **キーボード**：← →（PC・確認用。端まで向かい、離すとその場で停止）。

### 3-4. 調節パネル（⚙️＝保護者向け）
- **🍎 フルーツの量**：5段階（初期=2）。大きいほど多く降る。
- **💨 おちるスピード**：5段階（初期=2）。大きいほど速い。
- 「とじる」で閉じる。
- ※⚙️は親が難易度を変える用。3歳が誤って開いても「とじる」で戻れる。

### 3-5. 演出
- キャッチ時：10粒のカラフルなキラキラが弾ける。
- 効果音：やさしい「ポンッ」（鳴らせない端末では無音・ゲームは継続）。

### 3-6. 技術メモ
- **1枚のHTMLファイル**で完結（HTML＋CSS＋JS＋Canvas描画）。外部画像・外部音源・外部ライブラリ**ゼロ**＝オフラインで動く。
- くまさん・籠・壁・キラキラは**Canvasに手描き**。フルーツとUIアイコンのみ**絵文字**を使用。
- 画面サイズに合わせて自動リサイズ（高解像度対応）。最大幅700pxで中央寄せ。

## 4. タブレットに乗せる手順（対応方針）

1. **WebViewとChromeを更新**：Playストア →「Android System WebView」「Chrome」を更新（表示エンジンが新しくなり、文字サイズ等が完全に整う。無料・1回だけ）。
2. **ゲームを開く**：`index.html` をタブレットのブラウザで開く。
3. **ホーム画面に追加**：ブラウザのメニュー →「ホーム画面に追加」。アイコンができ、娘がトンッと押すだけで起動＝**アプリっぽく**なる。
   - これで十分。本物のAPK化は当面不要（必要になったら別途検討）。
4. **保険コード**：上記が出来ない端末でも崩れないよう、コード側に対策済み（§2の表）。

## 6. 【2.0】画像版＋ケーキ完成

- **見た目を実画像化**：背景・クマ（主役）・フルーツ6種・ケーキをジョーのAI絵に差し替え。
  - 原本は `original/`（高解像度PNG）、公開用の軽量版は `images/`。
  - 変換は `_make_assets.py`（Pillow）：①白背景を「フチからの塗りつぶし」で透明に抜く（内側の白＝コック帽・ケーキ本体は残す）②透明余白をトリミング③縮小④保存。背景2枚はJPEG。**約41MB→約1.9MB**。
  - 命名：`bg.jpg`／`chara.png`（クマ）／`cake.png`／`item-01〜06.png`（フルーツ）／`title-bg.jpg`（タイトル）。
- **画面レイアウト**（背景に合わせて）：**左＝青い床でクマが左右に動いてキャッチ**、フルーツは左側の上から落下。**右＝木のテーブルにケーキ**。
- **新ルール（クリア追加）**：キャッチしたフルーツが**ケーキの20か所に下→上の順で盛り付け**られ、**20個で完成（「できた！」演出）→数秒後にケーキを空にして再開**（エンドレス・罰なしは維持）。
- **位置の微調整**：`index.html` 冒頭の CONFIG（`BEAR`／`FALL`／`CAKE`／`SLOTS`／`SLOT_W`）を数値で調整するだけ。実機・プレビューで見ながら詰める。
- **Android 7.0対策**：据え置き。フルーツが画像になったので絵文字化け問題からは解放（スコアの🍰・⚙は古い端末でも安全）。音はtry/catch。
- **もどる・⚙設定を画像ボタン化**：共通パーツとして `src/shared/images/`（`btn-back.png`／`btn-settei.png`）に置き、`../shared/images/...` で参照。全ゲームで使い回す。
- **タイトル画面を追加**（各ゲーム共通仕様）：起動するとまず `title-bg.jpg`（くまさんのケーキ作り）を全画面表示。**左上もどる**（→おもちゃ箱メニュー）／**右上設定**（→調節パネル）。もどる・設定の大きさ位置は本体に準拠。index.html内のオーバーレイ（#title）で実装。**開始は「タイトルのどこを押してもスタート」**（`#title`のクリックで開始。`もどる`・`設定`だけ `closest('#t-back, #t-gear')` で除外）。画面下部に **`#start-hint`「タップで スタート」の文字**（白＋影、`@keyframes tap-bounce` でふわっと上下に弾む。`pointer-events:none`の飾り）。背景イラストを隠さないよう中央の画像ボタンは廃止（旧 `btn-start.png` は不使用）。文字サイズは `clamp()`＋`7vw`フォールバック（Android7対応）。
- 旧キャンバス版は `_index-canvas-backup.html` に保存（いつでも戻せる）。
