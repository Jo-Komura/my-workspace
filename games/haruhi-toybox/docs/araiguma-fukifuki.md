## 1. これは何
- はるひ（3歳）用ミニゲーム第4弾。中身は**こすって きれいにする**遊び。
- 画面中央の「曇った窓／ほこりの額（カード）」を指でこすると、下にかくれた**どうぶつ**がピカッと現れる。
- 技術の核＝Canvasの **`destination-out`**（＝Flashの消しゴム）。よごれレイヤーを指でなぞった所だけ消す。

## 2. はるひ基準（くまさん・アザラシと共通）
- **罰なし・ゲームオーバーなし・エンドレス**。
- スコア（✨）は**増えるだけ**。1匹きれいにするたびに +1・キラキラ・「ポンッ」。
- 操作は**こするだけ**＝3歳の指で迷わない。失敗の概念なし。

## 3. 画面・ルール
- 背景：お掃除のお部屋（今は仮グラデ。本物は後で差し込む）。
- 中央のカード：白い面＋あたたかい色のフチ。上によごれ（canvas）がかぶさっている。
- こする → よごれが消える → 一定量（**拭く量**しきい値）まで消すと**ピカピカ完成**（+1・キラキラ・ポンッ・カードがぽよん）。
- 完成 → カードがふわっと入れ替わり、**次のどうぶつ**＋新しいよごれ（キリン↔ゾウを順番に）。
- 上中央＝スコア「✨ ◯」。左上＝「もどる」、右上＝「設定」（ともに `shared` の画像アイコン btn-back.png / btn-settei.png ＝タイトル画面と統一）。
- ⚙パネル（親用・漢字表記）：見出し「設定」＋**「拭く量（1=かんたん）」1項目のみ（1〜5・初期3）**。小さいほど少し拭くだけで完成＝小さい子向け。固定px＝端末で巨大化しない“普通サイズ”。
  - しきい値（消えた割合）：`WIPE_THRESHOLD = [0.50, 0.60, 0.70, 0.80, 0.90]`（1=50% / 2=60% / 3=70% / 4=80% / 5=90%）。**このゲームの初期値は3＝70%**。

## 4. Android 7.0 対策（くまさん・アザラシと同じ作法）
- `clamp()` / `aspect-ratio` / `gap` を使わず、舞台・カードの寸法はJSで実寸指定。
- 2018年以降の絵文字を使わない。スコアの **✨（U+2728・2010年）** は古い端末でも安全。
- `canvas` の `destination-out` は Chromium 51 で動作可。消えた割合の判定は **6pxおきの間引き**で軽量化（`wipedFraction()`）。
- 効果音は **`shared/se/` の mp3 を共通ヘルパー `se()` で再生**（拭き拭き完了＝`finish.mp3`／共通ボタン＝`click.mp3`）。最初のタッチで自動再生制限を解除。鳴らせない端末でも try/.catch で握りつぶして継続。mp3はAndroid7のWebViewで再生可。
- **こすり音（`goshi.mp3`）はリピート再生＝“動かしている間だけ”**：`onMove` が `noteWipeMove()` を呼んで `lastMoveAt` を更新（＝こすっている印）。「鳴らす→鳴り終わったら `WIPE_GAP`(=500ms)あけて→また鳴らす」を繰り返すが、各再生の直前に「直近 `WIPE_IDLE`(=180ms) 以内に動いたか」を確認し、**指を止めると止まる／また動かすと再開**。`onUp`／完成`cleaned()`で`stopWipeSound()`（次を予約しないだけ＝今鳴っている音はぶつ切りにしない）。専用要素`wipeAudio`、音量・ミュートは `HTBSettings.seVolume()` に従う。間隔＝`WIPE_GAP`／止まった判定＝`WIPE_IDLE` で調整。押しただけ（動かさない）では鳴らない。

## 5. 絵の差し込み（後から格上げ）
- **ゲーム背景**（まだ無い・次回）：`images/bg.jpg` を置くと自動で本物に切替（`detectBg()`／無ければ仮グラデ）。背景が来たら舞台は画像の縦横比で中央に収まる。
- **どうぶつ（拭くと現れる絵）**：`index.html` 冒頭の **`ANIMALS` 配列に1行足すだけ**で増える。今はキリン・ゾウの2匹。
  - 例：`var ANIMALS = ['images/giraffe.jpg', 'images/elephant.jpg', /* ここに足す */];`
  - 絵は**白背景**でOK（カードの白い面に馴染む）。正方形に近いほどキレイ（`object-fit:contain`で中央表示）。
